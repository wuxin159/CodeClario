# 代码灵 · CodeClario

AI 驱动的可视化编程学习平台，提供 C、C++、Python 各18节基础课程。

AI围绕课程引入、运行结果、修改和理解检查主动提供教学引导；可视化帮助学习者观察自己的代码怎样执行。

## 当前功能

- 每日AI学习安排：根据当前任务和学习记录生成计划，支持调整时间、语言和学习意愿。
- 课程实践：代码编辑、标准输入、真实编译运行、样例检查和草稿恢复。
- 执行回放：受支持程序的变量、函数调用、指针关系和对象状态；课程概念示例另行标注。
- 错误实验：独立修改、运行与对比，不代替主课程成绩。
- 理解检查：区分独立作答、辅助作答、订正和重复题。
- 账户与记录：SQLite保存个人草稿、任务、运行和作答记录。

## 技术结构

| 目录 | 内容 |
| --- | --- |
| `src/` | React、TypeScript与CodeMirror前端 |
| `server/` | Express服务、AI流程、账户与数据库 |
| `shared/` | 三语言课程、类型和教学模型 |
| `runner/` | Docker隔离执行器与Python/GDB状态采集 |
| `public/` | 网站Logo与实际产品预览图 |

大模型通过服务端DeepSeek接口接入。程序运行和判题由执行器完成，不由模型猜测结果。

项目为原创编程学习应用，使用React、Express、CodeMirror等开源依赖；依赖版本以`package-lock.json`为准。


## 本地运行

需要 Node.js **24或以上**、npm和可运行Linux容器的Docker环境。C/C++原生回放目前在Linux x86-64执行器验证。

1. 在项目目录安装依赖：

   ```bash
   npm ci
   ```

2. 将 `.env.example` 复制为 `.env`，填写自己的 `DEEPSEEK_API_KEY`。不要提交 `.env` 或实际密钥。未连接AI时，仍可使用已有课程及普通练习功能。

3. 构建执行器与前端，然后启动：

   ```bash
   npm run runner:build
   npm run build
   npm start
   ```

4. 打开 `http://127.0.0.1:3000`，注册自己的账户。

开发模式使用 `npm run dev`。当前启动脚本使用`tsx`，安装依赖时不要省略开发依赖。

## Ubuntu服务器首次后台安装

在Node.js和Docker已安装、源码及镜像已构建的前提下，可使用`deploy/setup-service.sh`完成首次后台配置。脚本针对以下独立布局：

- 源码：`/opt/codeclario/app`
- Node.js：`/opt/codeclario/runtime/node`
- 新数据库：`/var/lib/codeclario/learning.sqlite`
- 服务器密钥文件：`/etc/codeclario.env`，root权限600，不进入源码仓库
- 后台服务：`codeclario.service`，使用专用账户和Docker附加组

使用root在源码目录执行`bash deploy/setup-service.sh`。密钥从服务器终端隐藏读取，不通过命令行参数输入；验证连接后再保存。已有账户、数据目录或配置时脚本会停止，不覆盖原内容。

应用监听本机`127.0.0.1:3000`，执行并发为1。需要另行配置现有Nginx反向代理和HTTPS后再注册登录；服务使用Secure Cookie。首次安装脚本不用于日常更新。日常更新保留外部密钥和数据，拉取源码、构建后重启应用；执行器变化时另行重建镜像。

## 配置与数据

配置项见 `.env.example`。默认数据库为项目目录外的 `../Data/learning.sqlite`，首次启动自动创建。可用 `DATABASE_PATH` 指定其他位置。部署时应单独保存并备份数据库，重启服务不会重置已有账户。

`RUNNER_MAX_CONCURRENT`控制同时执行的程序数量，可设为1、2或3，默认3。约2GB内存的演示服务器建议先设为1，再根据实际资源占用调整。

`node_modules/`、`dist/`、本地环境文件和数据库不进入Git；部署时安装依赖并重新构建。

## 能力边界

真实回放有语法、时间和数据量限制，不是任意程序的完整内存调试器。C/C++回放是同代码、同输入的另一次隔离调试执行，并核对普通运行输出；地址只属于该次调试运行。Python类的普通执行可用，当前尚无类的真实状态回放。不支持或采集不足时会显示实际状态，并保留普通运行结果。

课程示例、自己代码的执行、实验结果与理解检查分别记录；一次通过不等同于证明学习者已经掌握全部知识。
